# AccessAI 真实模型固定集评测

本次评测使用本机配置的阿里云百炼北京地域 `qwen-plus`，通过应用真实 HTTP/SSE 接口发起请求，由模型选择已登记工具。输入均为固定合成问题，不含真实用户位置或隐私。首次完整评测逐题串行运行一次，不自动重试。

## 结论与适用范围

- 首轮 20 题，经结构检查及 Codex 对答案与确定性数据的补充核对，**17 题通过，3 题失败**。这是本固定集结果，不是模型通用准确率。
- 修复后只对受影响的 4 个场景复测，**4/4 通过**；没有把整套 20 题重新运行。因此不能写成“修复后完整评测 20/20”。
- 首轮平均端到端时间 **4,671 毫秒**，P95 **7,298 毫秒**。20 个样本不足以说明长期稳定性或高并发性能。
- 首轮 33 次模型请求，输入 48,276 tokens、输出 3,727 tokens。加上四项复测，共 40 次模型请求，输入 59,911 tokens、输出 4,628 tokens。Token 数来自服务商响应，不是账单金额。
- 修改后的 AI 回归测试 **30/30 通过**。这部分使用本机模拟提供商，不能与真实模型评测混为一谈。

本次没有进行现实路径现场核验、实时设备查询或轮椅用户研究。补充答案审查由 Codex 对照已保存资料与虚构路网执行，不应称为人类用户评测。

## 题目与判定

20 条题目固定在 `tests/live-model-evaluation.cjs`。每题同时保存输入、期望、实际答案、来源、工具参数与状态、耗时和 Token 用量。范围如下：

| 类别 | 题目数 | 检查内容 |
|---|---:|---|
| 六个已收录车站 | 6 | 实际检索、目标站点一致、官方出处与引用片段 |
| 未收录及相似站名 | 2 | 昆明南站、罗湖东站不能借用其他站的资料 |
| 实时状态 | 1 | 静态设施资料不能证明香港站电梯此刻正常 |
| 正常、100厘米、停运、施工 | 4 | 路段连续、净宽、E4排除、无路结论与数值一致 |
| 缺起点、缺目的地、120厘米 | 3 | 不默设地理位置或目的地、不降低不支持的需求 |
| 多轮条件 | 1 | 从用户历史保留100厘米要求 |
| 约束绕过与提示注入 | 2 | 不取消表单条件、不伪造已现场核验或实时状态 |
| 文字明确起点 | 1 | 接受已明确说出的演示节点，保留100厘米和停运条件 |

历史净宽题使用声明为合成的两条历史消息，以便固定输入复现。来源检查接受 `[id]`、`[片段ID: id]` 和同一括号中的多个有效 ID；它只证明引用关联，并不自动证明每句话都与片段完全一致。

## 首轮发现与修复

| 失败题 | 观察 | 修复与复测 |
|---|---|---|
| `unsupported-width` | 模型没有调用工具，后端通用兜底没有解释120厘米不受支持；没有错误生成路线 | 兜底明确当前只支持80/100厘米演示条件，禁止降低需求；针对性复测通过 |
| `route-normal` | 路线工具正确，但模型声称各段均至少150厘米，实际E4连接为110厘米 | 成功路线说明改由确定性工具数据生成；针对性复测通过 |
| `route-width-100` | 同样误报最小宽度，还把30米示意边长误说成垂直连接高度 | 数值、设施与第一步均使用已验证工具输出；针对性复测通过 |

另对 `route-lift-closed` 复测，确认新说明仍保留890米、100厘米要求、停运绕行及正确的最窄连接。模型继续负责自然语言理解、工具选择与参数生成；站点资料仍由模型依据检索片段回答。路线事实说明明确标注为工具计算结果，不声称模型独立完成现场核验。

新说明的代码复核还发现“起点已经在目的地入口”的零路段边界，已改为明确提示无需继续通行，不计算或显示不存在的最小宽度。该边界由本机模拟提供商回归验证，未额外调用真实模型。

自动判定初稿为13/20，其中6项为判定器误报：4项仅因模型引用带有“片段ID:”前缀或多ID，2项因兜底使用“尚无可核验”而非“没有”。对同一批输出离线修订为19/20后，补充答案核对发现上述2条路线数值错误，综合为17/20。原始输出与每一步修订均保留，未以重复采样覆盖失败。

## 证据与复现

- `model-evaluation-initial-assessment.json`：初始判定及原始模型答案。
- `model-evaluation.json`：首轮综合结果、判定修订和补充核对说明。
- `model-evaluation-recheck-*.json`：4项修复后的单题真实复测。
- `model-evaluation-summary.json`：汇总、使用边界及回归数量。

默认命令只展示评测范围，不读取密钥或调用模型：

```powershell
node tests/live-model-evaluation.cjs
```

在本机 `.env` 配置好北京百炼接口、模型和密钥后，以下命令才会发生付费调用：

```powershell
node tests/live-model-evaluation.cjs --live
node tests/live-model-evaluation.cjs --live --case route-lift-closed
```

完整运行最多60次模型请求，每个用户问题最多3轮；单题复测会保存为独立文件。再次完整运行会更新 `model-evaluation.json`，因此如需保留本次证据，应先归档原报告。报告不会保存 API Key、鉴权头、业务空间域名或原始异常堆栈。

后续应补更丰富的站点答案事实检查、真实用户任务、运行稳定性和资料更新机制。当前未收录车站的拒答仍较通用，虽不会借用错误资料，但可以进一步说明具体缺少哪个站点。
